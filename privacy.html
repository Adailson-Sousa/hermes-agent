Política de Privacidade

Última atualização: novembro de 2026.

1. Quem somos

O Hermes-Agent é um assistente pessoal de automação operado por Adailson de Sousa Bastos (ADINFO Soluções em Informática), para uso exclusivo do próprio operador.

2. Quais dados o aplicativo acessa

Mediante autorização do operador, o aplicativo acessa apenas a conta Google do próprio operador, com o objetivo de ler e editar planilhas, arquivos do Google Drive e eventos de agenda usados na gestão da empresa e das finanças pessoais.

3. Como os dados são usados

Os dados são usados somente para executar as tarefas solicitadas pelo operador (por exemplo, registrar um atendimento ou consultar a agenda). Não usamos esses dados para publicidade, não os vendemos e não os compartilhamos com terceiros.

4. Armazenamento e segurança

Os tokens de acesso ficam armazenados apenas no servidor privado do operador. Nenhum dado de usuário Google é enviado a terceiros para outros fins.

5. Uso de dados de usuários do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Revogação de acesso e exclusão

O operador pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e apagar os tokens armazenados no servidor.
